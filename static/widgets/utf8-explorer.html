1 byte (ASCII) 2 bytes 3 bytes 4 bytes

Every character is one or more Unicode code points; UTF-8 stores each code point as 1–4 bytes. ASCII stays 1 byte; accents and many scripts take 2–3; most emoji take 4. A byte-level tokenizer's alphabet is exactly these byte values (0–255) — which is why it can never hit an out-of-vocabulary character.
