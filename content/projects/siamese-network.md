**Code:** [github.com/pranavpandey2511/Siamese-Network](https://github.com/pranavpandey2511/Siamese-Network)

An implementation of Siamese networks for **one-shot similarity learning** — the setting where a model must recognize new classes from just one example, by learning an embedding space where similar items sit close together instead of learning fixed class boundaries.

This pattern underpins face verification, signature matching, and low-data classification problems (I later applied the same family of ideas to one-shot symbol spotting in engineering drawings at Wipro).

See the [repository](https://github.com/pranavpandey2511/Siamese-Network) for notebooks and training code.
