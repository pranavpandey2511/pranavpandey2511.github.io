Threadweave is a Python library for building LLM-powered applications faster. It wraps LangChain behind a smaller, more ergonomic API — keeping the power of chains, tools, and retrieval while cutting the boilerplate that slows down prototyping.

## Highlights

- Simple, opinionated interfaces over common LangChain patterns
- Faster path from idea → working LLM app
- Pure Python, easy to drop into existing projects

Check out the [repository](https://github.com/pranavpandey2511/threadweave) for docs and examples — issues and PRs welcome.
